# 🦉🌸 모나용평 산목련 축제 게임

발왕산 산목련 축제를 위한 모바일 미니게임입니다. 부엉이를 조작해 떨어지는 산목련을 받고, 점수를 캡처해 응모 이벤트에 참여할 수 있어요.

## 🎮 게임 특징

- 🦉 귀여운 부엉이 캐릭터가 주인공
- 🌸 산목련(+10점), 황금꽃(+50점), 낙엽(-1♥), 💥밤송이(-3♥) 4종 아이템
- ❤️ **황금꽃 3개 모으면 ♥ 라이프 +1** (최대 5칸)
- 🦉 **부엉이 진화 시스템** — 레벨이 오를 때마다 외형 업그레이드:
  - LV 1-5: 🥚 새내기 (기본)
  - LV 6-10: 🎀 견습생 (리본)
  - LV 11-15: 👑 베테랑 (황금 왕관)
  - LV 16-19: ✨ 마법사 (망토 + 별)
  - LV 20: 🏆 전설 (무지개 깃털 + 후광)
- 🏆 **20레벨 시스템** — 각 레벨마다 클리어 화면 등장
- 📈 후반으로 갈수록 속도/낙엽 비율/동시 낙하 증가
- 🎬 **레벨 20 클리어 시 특별 엔딩** — 부엉이가 손 흔들며 인사하는 애니메이션
- 🔥 콤보 시스템으로 추가 점수
- 🎵 활기찬 봄날 BGM (Web Audio API 자체 작곡)
- 📸 결과 자동 캡처 → 구글 폼 응모 자동 연결
- 📱 모바일 100% 최적화 (터치, 진동, 안전영역 대응)
- 🌐 외부 의존성 0 — 단일 HTML 파일로 모든 게 동작

## 🚀 GitHub Pages 배포 방법 (5분이면 완료)

### 1️⃣ 새 저장소 만들기

1. https://github.com 로그인 후 우측 상단 **+** → **New repository**
2. 저장소 이름 입력 (예: `mona-magnolia-game`)
3. **Public** 선택 (Pages 무료 사용을 위해)
4. **Create repository** 클릭

### 2️⃣ 파일 업로드

이 폴더의 모든 파일을 업로드합니다:
- `index.html` ← 메인 게임 파일
- `404.html` ← 잘못된 경로 안내 페이지
- `.nojekyll` ← Jekyll 처리 건너뛰기 (속도/안정성)
- `README.md` ← 이 문서

**업로드 방법:**
- 새로 만든 저장소 페이지에서 **uploading an existing file** 링크 클릭
- 위 파일들을 모두 드래그 앤 드롭
- 하단의 **Commit changes** 버튼 클릭

> ⚠️ `.nojekyll` 파일은 점(.)으로 시작해서 일부 OS에서 숨김 처리되니, 업로드할 때 빠지지 않았는지 확인하세요.

### 3️⃣ GitHub Pages 활성화

1. 저장소 페이지에서 상단 **Settings** 탭 클릭
2. 왼쪽 사이드바에서 **Pages** 클릭
3. **Source** 영역에서:
   - **Branch**: `main` 선택
   - **Folder**: `/ (root)` 선택
   - **Save** 클릭
4. 1~2분 정도 기다리면 상단에 **"Your site is live at https://..."** 메시지가 표시됩니다.

### 4️⃣ 친구들에게 공유! 🎉

생성된 URL은 보통 다음 형태입니다:
```
https://본인깃허브아이디.github.io/mona-magnolia-game/
```

이 URL을 카톡, 문자, QR코드로 공유하면 모바일에서 바로 게임이 시작됩니다.

### 난이도 조절
모든 레벨 난이도는 `getLevelConfig(lv)` 함수에서 계산됩니다.
- **레벨당 목표 산목련 수**: `targetCatch: Math.floor(8 + t * 16)` (8개 → 24개)
- **낙하 속도**: `speed: 1.8 + t * 5.2` (1.8 → 7.0)
- **생성 간격**: `spawnInterval: Math.max(900 - L * 35, 250)` (ms)
- **낙엽 비율**: `leafChance: 0.12 + t * 0.33` (12% → 45%)
- **동시 낙하 시작 레벨**: `multiSpawn: L >= 12 ? 2 : 1`
- **시작 라이프**: `let life = 3;`

> `t`는 0~1로 정규화된 진행률, `L`은 현재 레벨(1~20)

## ❓ 문제 해결

**Q. Pages 설정했는데 404 페이지만 떠요**
→ 1~2분 더 기다려 보세요. 배포에 시간이 걸립니다. 그래도 안 되면 Settings → Pages에서 Branch 설정을 다시 확인하세요.

**Q. 모바일에서 음악이 안 나와요**
→ iOS Safari는 사용자가 화면을 한 번 터치한 후에만 소리가 재생됩니다. **「축제 시작」 버튼**을 누르면 음악이 시작됩니다. (브라우저 정책상 자동 재생 불가)

**Q. 카톡에 링크 보냈는데 미리보기가 이상해요**
→ GitHub Pages는 카톡 캐시가 갱신되는 데 시간이 걸릴 수 있어요. URL 끝에 `?v=2` 같은 파라미터를 붙여 다시 공유해 보세요.

**Q. 게임이 너무 어려워요/쉬워요**
→ 위 "난이도 조절" 섹션 참고하여 `index.html`을 수정하세요.
